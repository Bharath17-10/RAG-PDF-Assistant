# 🤖 AI PDF Chatbot

An AI-powered PDF chatbot built using FastAPI, LangChain, FAISS, HuggingFace Embeddings, and Groq LLM.

## Features

- 📄 Upload PDF documents
- 💬 Ask questions about PDFs
- 🔍 Semantic search using FAISS
- 🤖 AI-powered answers
- 🌙 Modern responsive UI
- ⚡ FastAPI backend

## Tech Stack

- Python
- FastAPI
- LangChain
- FAISS
- HuggingFace Embeddings
- Groq LLM
- HTML
- CSS
- JavaScript

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/AI-PDF-Chatbot.git

cd AI-PDF-Chatbot

pip install -r requirements.txt

uvicorn app.main:app --reload
```
